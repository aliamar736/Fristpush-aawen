# تسليم الملكية والحسابات

المبدأ: **كل حساب يُفتح باسم الجهة المالكة لـ«عاون» وبريدها المؤسسي**، ويُضاف المطورون كأعضاء بصلاحيات محددة يمكن سحبها.
لم يُنشأ أي حساب استضافة أو متجر أو مزود خارجي أثناء التنفيذ، ولم يُنشر أي شيء للعامة.

## 1. الشيفرة
- المستودع هنا (git، فرع `main`). أنشئوا مستودعًا خاصًا باسم الجهة (GitHub/GitLab Organization) وادفعوا إليه:
  `git remote add origin git@github.com:<org>/aawen.git && git push -u origin main`
- فعّلوا حماية الفرع الرئيسي ومراجعة الطلبات وتشغيل `scripts/test.sh` في CI.

## 2. الاستضافة
| المورد | يُفتح باسم | ملاحظات |
|---|---|---|
| خادم/منصة حاويات | الجهة | صلاحيات المطورين عبر IAM، لا مشاركة لكلمات مرور الجذر |
| PostgreSQL + PostGIS مُدار | الجهة | النسخ التلقائي + نسخنا عبر `backup_db` |
| S3/R2 للوسائط والنسخ | الجهة | حاوية خاصة، Versioning، حذف المفاتيح القديمة بعد التسليم |
| النطاق (مثلًا aawen.ly) وDNS | الجهة | قفل التحويل، التجديد التلقائي |
| شهادات TLS | تلقائي (Let's Encrypt/المنصة) | |
| مدير الأسرار | الجهة | كل الأسرار في المتغيرات؛ لا شيء في المستودع (`.env.example` فقط) |

## 3. متاجر التطبيقات
| المتجر | الحساب | الكلفة التقريبية (تحقق من السعر الحالي) | ما يلزم |
|---|---|---|---|
| Google Play | Play Console باسم منظمة (D-U-N-S) | رسوم تسجيل لمرة واحدة (~25$) | مفتاح رفع التطبيق (Play App Signing)، سياسة خصوصية منشورة، نموذج أمان البيانات |
| Apple App Store | Apple Developer Program كمنظمة (D-U-N-S) | اشتراك سنوي (~99$) | App Store Connect، شهادات التوقيع، سياسة الخصوصية، ملصقات الخصوصية |

- معرّف الحزمة المقترح: `ly.aawen.app` (يُحدد عند `flutter create --org ly.aawen`).
- احتفظوا بمفتاح التوقيع (keystore) في مدير الأسرار ونسخة احتياطية آمنة؛ فقدانه يمنع تحديث تطبيق أندرويد إن لم يُستخدم Play App Signing.
- الشعار: استبدلوا الأيقونات المتتبَّعة بالأصل المتجهي الرسمي قبل الرفع (`brand/README.md`).

## 4. الخدمات الخارجية
راجعوا `INTEGRATIONS.md`: مزود SMS، Firebase، مزود الدفع، مفتاح الذكاء الاصطناعي (اختياري)، مزود البلاطات. كل منها يُفتح باسم الجهة.

## 5. تسليم مدير النظام الأول
1. على خادم الإنتاج: `python manage.py create_first_admin --phone <هاتف المدير> --name "<الاسم>"` (كلمة المرور تُكتب تفاعليًا ولا تُخزن في أي ملف).
2. المدير ينشئ بقية الحسابات من «المستخدمون والأدوار» ويمنح الأدوار بنطاقها (منطقة/جهة). كل منح وسحب مسجّل.
3. افصلوا الأدوار المالية: المحاسب ≠ المراجع المالي ≠ مسؤول المبادرة (النظام يفرض ذلك على كل عملية).
