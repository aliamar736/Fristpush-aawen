# عاون — AAWEN
**مع بعض نعاونوا** · منصة ليبية للمشاركة المجتمعية (تبدأ من طرابلس).

لكل مشكلة في الشارع ملف واحد: رقم متابعة، جهة مختصة، مسؤول متابعة، سجل تحديثات، احتياجات، أدلة إنجاز يؤكدها طرف مستقل، وإمكانية الاعتراض وإعادة الفتح — مع تطوع ومساهمات عينية ومالية شفافة.

| المجلد | المحتوى | الحالة |
|---|---|---|
| `backend/` | Django 5.2 + DRF + PostgreSQL/PostGIS + Celery/Redis | يعمل، 62 اختبارًا ناجحًا |
| `web/` | React + TypeScript (Vite): المواطن، الإدارة، الجهات، الميدان | يعمل، 22 اختبار E2E + 4 وحدات |
| `mobile/` | Flutter (أندرويد/آيفون) | **الكود مكتوب، لم يُبنَ** (Flutter غير متاح في بيئة التنفيذ) |
| `brand/` | الشعار متجهيًا (تتبُّع من لوحة الهوية) والأيقونات | يحتاج الأصل الرسمي قبل الطباعة/المتاجر |
| `infra/` | Docker Compose (db, redis, minio, api, worker, beat, web) | الصيغة صالحة، لم تُبنَ الصور |
| `docs/` | المتطلبات والبنية والتشغيل والتكاملات والتسليم ونتائج الاختبارات واللقطات و`openapi.yaml` | |

## جرّبه في المتصفح (GitHub Codespaces) — دون تثبيت أي شيء
1. في صفحة المستودع على GitHub: **Code ← Codespaces ← Create codespace on main**.
2. انتظر حتى ينتهي الإعداد في المرة الأولى (5–10 دقائق: تثبيت المكتبات، إنشاء قاعدة البيانات، بيانات العرض).
3. افتح تبويب **PORTS** واضغط أيقونة الكرة بجانب **AAWEN app (5173)** إن لم يُفتح التطبيق تلقائيًا.
4. سجّل الدخول برقم من حسابات العرض (الرمز يظهر في شاشة الدخول لأن الرسائل محاكاة):
   `0910000012` مواطن · `0910000002` مراجع · `0910000003` منسق · `0910000004` موظف جهة النظافة · `0910000014` فني ميداني · `0910000010` محاسب · `0910000011` مراجع مالي · `0910000001` مدير النظام.

بيئة Codespaces للعرض والتجربة فقط: بيانات «تجريبي»، دفع بمحاكٍ، رسائل محاكاة. السجلات في `/tmp/aawen/`، وإعادة التشغيل: `bash .devcontainer/start.sh`.

## البدء السريع
راجع `docs/OPERATIONS.md` §1. باختصار:
```bash
cd backend && python3 -m venv .venv && . .venv/bin/activate && pip install -r requirements-dev.txt
cp .env.example .env && python manage.py migrate && python manage.py seed_demo && python manage.py runserver
cd ../web && npm ci && npm run dev      # http://localhost:5173
```
وثائق API التفاعلية: `http://localhost:8000/api/v1/docs` — والملف الثابت `docs/openapi.yaml`.

## مبادئ غير قابلة للتفاوض في الكود
- لا يُغلق بلاغ بمرور الوقت أو بعدم رد الجهة، ولا يغيّر الذكاء الاصطناعي أي حالة أو مال.
- الإحالة ≠ استلام الجهة؛ الإنجاز يحتاج إثبات المنفذ **وتأكيدًا مستقلًا**.
- التعهد ≠ دفعة؛ صورة التحويل ≠ دفعة؛ الإشعار المكرر لا يُسجّل مرتين؛ السجل المالي غير قابل للتعديل.
- استقبال المال الحقيقي معطّل حتى الضبط والتفويض. لا محافظ بين الأفراد.
- هوية المبلّغ لا تُعرض للعامة، والوسائط لا تُنشر قبل المراجعة والطمس.
- بيانات العرض معلّمة «تجريبي» ومرفوضة في الإنتاج.
