# أصول هوية «عاون»

| الملف | الاستخدام |
|---|---|
| `svg/aawen-mark.svg` | الرمز على خلفية فاتحة |
| `svg/aawen-mark-on-dark.svg` | الرمز على خلفية بترولية (الجزء البترولي يصبح عاجيًا كما في لوحة الهوية) |
| `svg/aawen-lockup.svg` / `-on-dark` | الرمز + «عاون» + «مع بعض نعاونوا» + AAWEN |
| `svg/aawen-wordmark.svg` | الكلمة العربية والعبارة فقط |
| `svg/app-icon-*.svg`, `png/*` | أيقونات التطبيق والويب والمتاجر |

## مصدر الأصول وحدودها
- لم يُرفق أصل متجهي أصلي. الأصول هنا **تتبُّع متجهي (potrace)** لمنطقة الشعار في لوحة الهوية (`/mnt/user-data/uploads/…png`)،
  مع تصنيف كل بكسل إلى أقرب لون من ألوان الهوية الأربعة وتعبئة النتيجة بالقيم الدقيقة (#123F46، #20B7A5، #F4B544).
- التطابق البصري عالٍ عند أحجام العرض المعتادة، لكن الحواف تحمل تموجات طفيفة موروثة من الصورة النقطية (دقة اللوحة 1536×1024).
- **مطلوب من صاحب الهوية:** ملف الشعار الأصلي (AI/SVG/PDF) لاستبدال هذه النسخ قبل الطباعة الكبيرة أو رفع التطبيق للمتاجر.
  الاستبدال لا يتطلب تعديل الكود: ضع الملفات بنفس الأسماء ثم شغّل `python tools/build_icons.py`.
- لم تُستخدم صورة لوحة الهوية كاملة كشعار في أي مكان.

## إعادة التوليد
```
python tools/trace_brand.py <brand-board.png> svg
python tools/build_icons.py
```
يتطلب `potrace` و`cairosvg` و`numpy` و`Pillow`.
